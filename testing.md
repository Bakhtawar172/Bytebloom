
# Bytebloom Testing Checklist

## 1. Navigation
- [ ] Home, Courses, Cart and Contact pages open correctly.
- [ ] Mobile navigation opens and closes.

## 2. Course Catalogue
- [ ] Course cards display correctly.
- [ ] Search works by course name, category and level.
- [ ] Category filter works.
- [ ] Price and rating sorting work.
- [ ] Sold-out courses cannot be added.

## 3. Shopping Cart
- [ ] Courses can be added and removed.
- [ ] Quantity buttons update totals.
- [ ] Quantity cannot exceed 10 per course.
- [ ] Subtotal, discount and total are correct.
- [ ] Cart data survives a page refresh.

## 4. Checkout and Contact
- [ ] Empty cart cannot be checked out.
- [ ] Invalid checkout fields show errors.
- [ ] Valid checkout clears the cart.
- [ ] Contact form validates required fields.

## 5. Responsive Design
- [ ] Layout works at desktop width.
- [ ] Layout works at phone width.
- [ ] No unwanted horizontal scrolling appears.
